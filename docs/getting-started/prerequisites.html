Tools

Tool Needed for Required
.NET 10 SDK The Web API, the Aspire AppHost and the Atom build Yes
Atom tool, installed by dotnet tool restore from dotnet-tools.json Running build, test, setup and docs targets Yes
Docker The PostgreSQL and Azurite containers the AppHost starts, and the integration tests Yes
Node.js (with npm) The Chrome extension and the shared TypeScript packages Yes
Aspire CLI aspire run (dotnet run --project src/webapi/Invex.Passel.AppHost works without it). dotnet tool restore also installs the version the deployment uses, as dotnet aspire No
Flutter and the Android SDK The mobile app; the SDK's adb connects a phone on USB to your local API Mobile work only
Dev Tunnels CLI Reaching your local API from a phone that is not on USB Only for that

The API's HTTPS endpoint also needs a trusted ASP.NET Core development certificate:

dotnet dev-certs https --trust

Check your machine

From the repository root, run:

dotnet tool restore
dotnet atom SetupDevEnvironment

The target:

  • Reports any tools that are missing. It fails only if Docker or npm is missing.
  • Warns you if Docker isn't running or the HTTPS development certificate isn't trusted.
  • Creates src/mobile_app/.env from .env.example if it doesn't exist.
  • Installs the npm workspace in src (the shared TypeScript packages and the Chrome extension).
  • Fetches the mobile app's Flutter packages.

It's safe to run again at any time. Next, set up the Google OAuth clients.

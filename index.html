Passel

Passel sends links and text between your devices. Push something from your browser and it shows up on your phone, live.

The repository holds the apps that share one API:

Component Stack Source
Web API ASP.NET Core (.NET 10), Marten on PostgreSQL, hosted locally by .NET Aspire src/webapi
Chrome Extension TypeScript, Manifest V3, esbuild src/chrome-extension
Web App TypeScript, Preact, esbuild; also the landing, privacy and terms pages src/web
Mobile App Flutter (Android), Riverpod src/mobile_app

Builds, tests and docs are driven by Atom; see Build Targets.

Start here

  1. Install the prerequisites, then run dotnet tool restore and dotnet atom SetupDevEnvironment to check them.
  2. Set up the Google OAuth clients the apps sign in with.
  3. Run everything locally with the Aspire AppHost.
